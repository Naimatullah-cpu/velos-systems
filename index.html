Architectural Boundary

"Never ask the transport floor to become a philosopher."

Velos Systems decouples upstream cognitive reasoning and policy evaluation (Layer-7) from physical runtime enforcement (Layer-4). By anchoring execution boundaries directly to Linux kernel hooks (eBPF), Velos guarantees deterministic, sub-microsecond refusal at T=0 before state mutation can attach.

Core Specifications

  • Kernel-Resident PEP: Non-bypassable ingress packet interdiction via TC_ACT_SHOT and socket-layer reset.
  • Sub-Microsecond Latency: Mean execution latency of < 4.0 µs under concurrent load.
  • Asynchronous Telemetry: Immutable refusal receipts generated via ring buffers without blocking packet paths.
  • Fail-Closed Substrate: Immediate execution halt upon telemetry exhaustion or map loss.
