ASSURANCE ARCHITECTURE · BARE-METAL RUNTIME ENFORCEMENT

Where an autonomous authorization becomes physically falsifiable.

The AGCP Assurance Architecture positions the Layer-4 eBPF Policy Enforcement Point as the non-bypassable floor of consequential AI systems: bounded upstream authority matrices enter kernel transit, authority is verified synchronously at T=0, and un-authorized packets are deterministically severed before state mutation can attach.

Framework: AGCP / AEGF Conformance
PEP Substrate: Linux Kernel eBPF (tc-ingress)
Interdiction Latency: < 4.0 µs (O(1) Map Lookup)
Audit Posture: Pre-Consequence Refusal
FROM POLICY TO KERNEL ENFORCEMENT

Reasoning, authorization, and packet execution remain strictly separated functions.

The architecture explicitly prevents upstream cognitive engines from executing unmonitored egress. Semantic instructions cannot substitute for wire-level gates.

The Fundamental Recovery Invariant

"Recovery restores capability. Re-authorisation restores permission."
Technical readiness of a compute substrate must never be treated as sufficient evidence that an autonomous agent is legitimately authorised to resume consequential execution. When an invariant fractures, permission is revoked instantly at the socket floor.

WHAT THE SUBSTRATE ENFORCES

The question is not whether the policy is logged. It is whether the unauthorized packet can physically move.

INPUT

Bounded Authority Lease

Exact artifact version, present-tense authority lease, permitted IP/port egress scope, and active cryptographic token signature.

KERNEL GATE

Controlled Challenge

Hardware ring-buffer saturation tests, out-of-band token revocation, mid-flight parameter drift, and zero-trust transport boundary locks.

OUTPUT

Physical Evidence

Deterministic wire-level packet drops (TC_ACT_SHOT), connection reset emission, and cryptographic provenance receipts emitted via ring buffers.
